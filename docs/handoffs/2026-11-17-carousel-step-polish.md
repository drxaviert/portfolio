## Gotchas
- Subagent dev servers outlive their agent; stop them by PID (`netstat -ano | grep :<port>`) before removing a worktree. Windows file locks otherwise make the removal fail partway.
- Build from a copy (or stop dev first): `next build` wipes `.next` under a running dev server.
- The guard blocks loops and chained commands; run removals one command at a time.
